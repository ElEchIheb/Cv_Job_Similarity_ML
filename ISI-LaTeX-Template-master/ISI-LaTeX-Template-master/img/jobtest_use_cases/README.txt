JOBTEST — 9 DIAGRAMMES DE CAS D'UTILISATION

Contenu :
01_global                  Diagramme global des cas d'utilisation
02_authentification        UC-01 — Authentification et gestion de session
03_offres                  UC-02 — Gestion des offres d'emploi
04_candidats               UC-03 — Gestion des candidats
05_evaluation_cv           UC-04 — Évaluation d'un CV
06_analyse_approfondie     UC-05 — Analyse approfondie optionnelle
07_rapport_pdf             UC-06 — Génération du rapport PDF
08_classement              UC-07 — Classement de plusieurs candidats
09_historique              UC-08 — Historique et consultation des résultats

Formats :
- SVG : format vectoriel recommandé pour l'édition et l'export haute qualité.
- PNG : format raster à 180 DPI, directement exploitable dans LaTeX.

Conventions UML :
- association continue : interaction directe de l'acteur avec le cas d'utilisation ;
- «include» : comportement systématiquement requis par le cas principal ;
- «extend» : comportement optionnel ou conditionnel.

Les légendes «Figure 2.x» doivent rester dans le code LaTeX du rapport et ne sont
pas intégrées aux images, afin de préserver la numérotation automatique.
